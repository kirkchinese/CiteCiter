# Agent Note：覆盖层与生命周期所有权

日期：2026-08-23。布局选择后续由[可逆 grid 适配器](2026-08-23-reversible-host-grid-compatibility-adapter.zh.md)取代；生命周期要求仍有价值。

注册 shell.overlay 只授予附加表面，不授予父 frame 或 details 拖动柄的所有权。初版因此把布局限制在公开 overlay 内；后续独立兼容例外另有记录，不能扩展到不相关的宿主内部实现。

卸载时先停止接收新任务，请求取消并等待已接纳异步工作结束，再释放监听器与资源。只请求取消而不等待排空可能丢失终帧，或让回调继续访问已释放状态。

选区贡献应声明公开依赖并限定所属作用域；原生预览为可选服务，缺失时不能使其他插件功能无法加载。这些决定不修改宿主 Agent Loop 或持久 Session 格式。

仅保存在浏览器的“上次查看”指针按 origin 隔离。loopback 端口变化可能丢失该指针，但 Host Topic 仍持久存在。排查恢复时应区分客户端导航状态和会话数据所有权。
