# Agent Note：历史 DSH Web 版本范围

日期：2026-08-22。本文记录 0.4 发布时的 Web 兼容决定，不是当前支持范围。

CiteCiter 0.3.2 限定于 DSH 0.1.0-rc.7，导致使用 0.1.1 预发布线的 Web 用户被旧 peer 范围拒绝。核对 Host 与 Client 契约后，范围改为 >=0.1.1-rc.1 <0.1.1-rc.3，开发固定 rc.2。

兼容矩阵检查 rc.1 / Node 24 和 rc.2 / Node 22.19。来源元数据和 Session 格式保持不变。没有证据支持未来 API 的兼容性，因此不使用无上限的 peer 范围。

继续使用公开 Host 与 Web Client 服务；核对实际安装产物，不假定持续变化的 master 与安装版本一致。包矩阵通过不代表其他宿主或操作系统的交互验收完成。
