# Web UI 验收入口修正

日期：2026-09-12。范围：修复隔离 Web 验收的首次登录流程与文档，不修改运行代码或宿主。

## 决策

首次打开临时 DSH Web 服务时必须使用该进程打印的完整登录链接；认证后再使用不含 token 的地址。不能依据浏览器的 ERR_BLOCKED_BY_CLIENT 或同时出现的会话路由警告直接断言 localhost 被策略禁止或 Codex 连接损坏。原生控制未开放是独立限制。

## 证据

相同服务的裸地址返回 401、text/plain；启动登录链接返回 303、设置会话 Cookie 并跳转至根路径。同一 CUA 标签打开正常登录链接后加载 DSH。只读检查当前浏览器服务，text/plain 文档会被下载分类处理，未启用下载的普通导航使用 BlockedByClient 中止该响应。未修改浏览器策略、认证或缓存插件文件。

随后实际打开 CiteCiter 阅读器，540058 B 文档可翻至第 2 / 2 页，尾句“曲率描述平行移动的局部路径依赖。”完整且可选择。检查的是已有安装的 0.7.0-beta.3。没有执行新的模型请求，也没有把无来源 Session 的阅读检查记为 Topic 创建通过。
