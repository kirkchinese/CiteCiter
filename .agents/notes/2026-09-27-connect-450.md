# RC2 Web, Connect 4.50–4.52 and draft correctness

Historical implementation record for CiteCiter 0.9.0-alpha.1 on Web DSH 0.1.7-rc.2. Upstream Connect 4.50 was replaced by 4.52; the earlier 4.47 compatibility exception was removed. Current host requirements are in AGENTS.md. Detailed Web observations and candidate boundaries are in [the validation record](../../docs/validation/2026-09-27-connect-450.md).

## Final decisions

A retired source model creates an unsent Topic that explicitly requires a valid model selection. Model metadata changes only after host acceptance. Free question appends only to the selected unarchived Topic under the same source; archived, other-source or unselected destinations create. Other built-in actions create, and custom actions choose their target. Creating and preparing references never submit a model request.

Host get/list remain unchanged. Live membership checks in RC2 otherwise advertised Citer Sessions in the main list. Only exact registered owned instances route through the reversible flush adapter, with a public llm/stream checkpoint before model work. Owned title services use the Topic realm, not the root store. No Agent Loop or source log is changed.

Transcript position tracks a message anchor and within-message offset, observes delayed image/container geometry, and distinguishes restoration from reader scrolling. Observers release with their owner. Explicit user sends follow latest; independent streaming preserves reading position.

Learning examples use shared text/code schemas. Code preserves its language and whitespace, renders in native CodeBlock, and exports through a fence longer than any delimiter in its content. Only persisted readers accept old strings as text; logs are not rewritten. Field descriptions alone cannot make arbitrary code safe Markdown.

Model/effort popovers remain inside the viewport, reposition synchronously when contents change, and restore keyboard focus in submenus. Saving uses aria-disabled plus action guards instead of removing button focus. The atomic replacement helper only retries Windows sharing errors within a bounded interval; permanent failures preserve the original error and both old and pending data.

Document tools report UTF-16 length, exact bounds and continuation separately from response truncation. Invalid endpoints remain errors. Literal case-insensitive search runs against the original string so Unicode case expansion cannot shift offsets. First-answer suggestions respect strict user output constraints and only prepare drafts.

Keeping a conflicted local draft re-registers a local file if another window removed its durable bytes, then performs the existing compare-and-save check. Failure keeps resolution choices visible; disposed controllers ignore late responses. Source grants and model logs remain unchanged.

## Evidence and limits

Real Web regressions covered two-window text and file conflicts, exact download bytes, source-log isolation, first-answer suggestions, menu keyboard navigation, native title changes, queues and steering, stopping/continuing, structured code cards, PTC child calls, document pagination and Unicode reads. Cases remain attributable to their installed candidate; final README-only changes were checked by file equality.

Connect 4.50 and 4.52 each completed real image generation/editing tasks; folding tools preserved visible returned images. One earlier 120-second edit timeout remained a failure. Closing the panel allowed a real board capture to finish, and archiving during an image edit kept that Topic archived after completion. Image generation and optional local view_image are separate connector capabilities.

The Promise.all teaching response contained a factual overgeneralization and was corrected using a concrete rejection-plus-pending example. Tool success and attractive cards are not proof of factual correctness. The real structured HTML card preserved six lines, indentation and Chinese comments, with exact-copy and Markdown-export checks.

Windows build UNKNOWN remained intermittent and without a demonstrated root cause; no blind retry or security-setting change was introduced. The user accepted the upstream read-only PowerShell limitation for this alpha release. Linux/macOS did not receive functional acceptance.

Publication dry-runs exposed a mirror registry default and tarball --tag behavior. Publish commands explicitly select registry.npmjs.org, next and public access; dry-run does not establish upload authentication. User-performed npm publication and exact package hashes are recorded in [the release gate](../../docs/validation/2026-09-28-release-gate.md). No credentials, fake providers or temporary test scripts are retained.
