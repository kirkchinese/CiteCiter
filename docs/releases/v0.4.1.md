# CiteCiter v0.4.1

v0.4.1 makes CiteCiter more reliable during long conversations, retries, settings failures, and plugin reloads. Existing Topic files, Session logs, and settings keep their current format.

## What changed

- Follow-up suggestions no longer leak control markup into completed answers.
- Oversized source events no longer stop CiteCiter from reading later evidence.
- Retried creation and follow-up requests no longer create duplicate work.
- Settings actions now show loading, unsupported, success, and recoverable failure states.
- The learning panel keeps the main conversation visible when the supported DSH layout has enough room, and falls back to an overlay when it does not.
- Host and Client shutdown now cancel accepted work and wait for it to finish before unloading.
- DSH selections use the declared conversation dependency; Read Frog remains an optional best-effort adapter.

## Compatibility

- DSH Web `>=0.1.1-rc.1 <0.1.1-rc.3`.
- Node.js `^22.19.0 || >=24.0.0`.
- Existing v0.3.2 and v0.4.0 Topics and settings need no migration.
- Packaged DSH Desktop adaptation is deferred and is not claimed by this release.

The frozen Linux/Web artifact passed its package, upgrade, assembled keyless browser, and rc.1/rc.2 compatibility checks. Real-provider quality acceptance, real-Topic responsiveness measurements, and packaged Desktop acceptance are not included in this release.

## Install or upgrade

The npm package is not published yet. After npm publication, install or upgrade the Web profile with:

```sh
dsh plugin --profile web add @kirkchinese/dsh-citeciter@0.4.1
dsh plugin --profile web list --depth 0
```

Restart DSH Web and refresh the page afterward.
