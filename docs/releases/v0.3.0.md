# CiteCiter v0.3.0

v0.3.0 replaces v0.2's ordinary forked child Threads with private Observer Topics. A user can cite one committed model call while the source Agent's longer turn is still running, ask beside the selection, and continue a separate multi-turn learning conversation without adding noise to the main DSH Session list.

## Highlights

- A committed `assistant/message` is the Citation boundary; `turn/end` is not required for Observer.
- Rendered GFM selections map back to Host-verifiable raw Markdown ranges while preserving a separate visible quote for the learning UI.
- Every selection submission creates a new numeric Topic and a private standard DSH Session.
- The Topic-only `read_source_session` tool reads bounded committed evidence from one fixed source Session and records the exact captured seq in the Topic log.
- Source messages, reasoning, tool arguments, tool results, Citation text, and optional workspace files remain untrusted evidence.
- The private Agent runs with the DSH read-only sandbox and exposes only `read_source_session` plus the optional standard `read` tool.
- Topic conversations support streaming, multi-turn continuation, stop, DSH title generation, rename, archive/restore, model switching, and reasoning-effort selection.
- The browser UI keeps the real DSH programming shell: selection input appears beside the source text and a resizable right learning dock adds a private Topic rail beside the central coding conversation.
- Native DSH settings control the default Observer/Exact preference, source reasoning, source-file access, dock width, and last-Topic reopening.

## Context modes

Observer is the default. It starts with an empty private history, persists the Citation as untrusted context, and requires a source read before the first answer. Later source reads can use explicit seq ranges while the source Agent continues.

Exact Fork is advanced. It requires the Citation's source turn to contain `turn/end`, then seeds the private Topic Session through that stable boundary. `exact-when-available` uses this seed when possible and otherwise follows its documented Observer fallback.

## Private storage

Navigation metadata and DSH Session logs use separate private roots:

```text
$DSH_HOME/citeciter/workspaces/<base64url-source-id>/<topic-id>/topic.json
$DSH_HOME/citeciter/sessions/<dsh-project-key>/<encoded-topic-session-id>/session.jsonl
```

The first path owns source-to-Topic navigation. The second uses the standard DSH JSONL persistence layout with `compression: none` and `packChunks: false`. Topic Session ids link the two; neither path is scanned by the ordinary DSH Session list.

## Upgrade from v0.2.1

```sh
dsh plugin --profile web add @kirkchinese/dsh-citeciter@0.3.0
dsh plugin --profile web list --depth 0
```

Restart the corresponding DSH Web process after upgrading. v0.3 does not rewrite or import v0.2 child Sessions: those remain ordinary DSH data, while new discussions use the private v0.3 store. Verify that the installed profile actually reports `0.3.0`; a package-manager warning or completion line alone is not version evidence.

## Compatibility

This release targets DSH Web `>=0.1.0-rc.7 <0.1.0-rc.8`; the tested line is `0.1.0-rc.7`. It requires Node.js `^22.19.0 || >=24.0.0` and a configured model provider.

## Known limitations

- A selection must remain inside one committed assistant flow; unfinished chunks and cross-message selections are not citable.
- Renderer-generated KaTeX and footnote-number DOM is not citable until DSH exposes stable source positions for it.
- Exact Fork cannot start from an open source turn.
- Each source-tool result is capped at 128 KiB and reports truncation; callers must request another range when needed.
- v0.3 has no Topic-log compression or compaction, full-screen learning workspace, Topic search, UI delete button, complete localization, or cross-platform browser CI.
- Existing Topics survive a missing source Session, but new source reads fail until that Session becomes available again.
- DSH is prerelease software; a later DSH API line may require a CiteCiter update.
