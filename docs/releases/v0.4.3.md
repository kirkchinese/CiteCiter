# CiteCiter v0.4.3

这个版本恢复了整理选区逻辑时意外丢失的 Citer 功能。

## 修复内容

- 主 Agent 还在运行时，只要一次中间模型调用已经提交，就可以立即 Citer。
- 展开思考内容后，可以直接选择思考正文建立 Citer。
- 可以选择跨越“思考+回答”的连续内容。
- 旧版按纯回答正文保存的 Topic 继续可用，不需要迁移。

仍在流式输出、尚未提交的文字没有稳定来源，继续保持不可选。自动生成的思考折叠标题也不会被当成模型原文。

## 已测试

- 包内 76 项测试全部通过。
- 类型检查与正式构建通过。
- 在隔离的 DSH Web `0.1.1-rc.2` 页面中，外层轮次保持运行时，思考正文可以正常打开提问框并建立 Topic。
- Windows 与 macOS Desktop 适配仍暂缓，本版本只发布已经完成的 Web 修复。

## 安装或升级

```sh
dsh plugin --profile web add @kirkchinese/dsh-citeciter@0.4.3
dsh plugin --profile web list --depth 0
```

安装后重启 DSH Web 并刷新页面。

---

This release restores Citer for committed intermediate model calls while the surrounding Agent turn continues. Expanded reasoning and selections spanning reasoning and answer text are supported again. Existing text-only Topics remain compatible, while uncommitted streaming fragments and generated reasoning headers remain excluded.
