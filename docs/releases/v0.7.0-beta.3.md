# CiteCiter 0.7.0-beta.3

开发候选版本；仅推送代码与 Release 文档，不发布 npm、标签或 GitHub Release。

## 变更

- 增加八槽选文轮盘。默认按住右键、移向动作、松开执行；短按支持点击选择，中心、空槽、轮盘外和 Esc 取消。
- 默认提供自由提问、解释、找错误、翻译、定量板书、总结卡片，保留两个空槽。设置支持编辑提示词、输入要求、问答/讲解方式、侧边/悬浮位置、槽位顺序和触发键。
- 需要输入的动作显示提示，确认后打开问题输入框与模型选择器；直接动作使用设置中的默认模型。首轮请求使用选定模型，失败保留草稿和模型。
- 增加原生文件预览的“CiteCiter 学习”查看方式。宿主负责文件读取与刷新，CiteCiter 保存学习快照，并与独立阅读器共享完整文本分页。
- 增加可拖动悬浮窗及侧边/悬浮切换。保留 Topic 和草稿，原生详情全屏提供“悬浮查看”入口。
- 轮盘、提问框、悬浮窗采用半透明玻璃和短动效，支持减少动态效果及提高对比度。
- 分离手势、动作状态、执行、来源解析和 React 视图；修正来源切换期间的创建、重试身份、窄布局状态残留及其他设置刷新覆盖槽位草稿的问题。
- 修复客户端创建入口丢失处理模型和来源参数；对话与文档的首轮模型选择均已补充回归。
- 提问框在失焦、调整窗口和外部点击后保留问题与模型；主动关闭、Esc 或切换来源才取消。窗口缩小时输入框保持在视口内。
- 修复原生全屏预览遮挡轮盘、提问框、阅读器和悬浮窗；使用由公开 slot 管理生命周期的 React portal，侧边布局仍由独立适配器管理。
- 文档选区按原文定位，保留 Markdown 标题、链接和代码语法，支持全文引用；不改变主对话的渲染选区规则。
- 总结阶段先核对与纠错，再生成卡片，要求同步检查例子和参考答案；不增加第二轮应用级模型请求。自检不能替代独立事实验证。
- 修复深色主题下顶部操作按钮的文字对比度，颜色随宿主主题调整。

## 兼容与升级

宿主基线为 DSH 0.1.5-rc.1 / 社区 Desktop 2.0.9。原生文件集成使用可选 documentPreviews 服务，本机解析安装的对应子包为 0.1.5-rc.2，相关开发依赖固定到 rc.2。没有该服务时保留对话轮盘、独立阅读器和 Topic。

旧设置缺少轮盘字段时使用默认八槽；默认模型未指定时跟随来源。旧 Topic 和学习卡无需 CiteCiter 数据迁移。安装本地 tarball 后重启宿主并刷新客户端。Web 和 Desktop 使用各自的 profile；同时运行时使用不同 home。

## 验证与限制

已执行 184 项行为测试、Host/Client 类型检查、构建及真实无密钥 DSH 的来源/Topic/五阶段/板书/卡片/重启回归。安装包、实际 Web/Desktop 操作和真实模型结果见[本轮验收记录](../validation/2026-09-12-acceptance.md)。

原生集成覆盖 UTF-8 文本、Markdown 源文和常见代码文件，不接管宿主其他渲染器选区，不支持 PDF 文本层、Word 或 OCR。来源需要 Session 地址。已检查实际轮盘输入、首轮模型、全屏预览及悬浮查看；部分主题、DPI、模式和自定义设置组合仍未覆盖。真实模型能完成五阶段和卡片保存，但自检后仍可能保留错误推广和不准确的来源定位。工程流程通过不代表教学内容已核实。

## English

Development candidate; code and release documentation only. No npm publication, tag or GitHub Release.

- Adds an eight-slot selection wheel: hold right mouse, move and release, with click and keyboard alternatives, cancellation and configurable triggers.
- Includes free questions, explanations, error finding, translation, quantitative boards and summary cards, plus two empty slots. Custom modes configure prompts, required input, Q&A/learning and side/floating presentation.
- Required-input modes show a question form and model selector. Direct modes use the configured default model; first requests route correctly and retries preserve drafts.
- Adds an optional native “CiteCiter 学习” document renderer with host-owned loading/refresh and complete learning snapshots. Both readers share lossless pagination.
- Adds a draggable floating panel, presentation switching and an explicit floating entry during native details fullscreen. Glass surfaces and short animations respect reduced motion and increased contrast.
- Separates gesture, action state, execution, source parsing and React views; fixes source-change races, retry identity, stale narrow-layout state and unsaved slot drafts being overwritten by unrelated settings refreshes.
- Fixes dropped first-turn model and captured-source arguments in the client façade, with conversation and document regressions.
- Preserves question forms and models across blur, resize and outside clicks; explicit close, Escape or source changes cancel them. Forms stay within the resized viewport.
- Uses slot-owned React portals to keep the wheel, prompt, reader and floating view above native fullscreen. Side layout retains its isolated host adapter.
- Resolves document selections as literal source, including Markdown syntax, code and full-document quotes; rendered conversation matching is unchanged.
- Checks and corrects before summary cards, including examples and reference answers, within the same request. This self-check is not independent factual verification.
- Fixes dark-theme header button contrast using the host's theme-aware label color.

The baseline remains DSH 0.1.5-rc.1 / Desktop 2.0.9. Native preview development dependencies target the locally resolved 0.1.5-rc.2 subpackages; the service is optional. Missing settings receive defaults, and existing Topic data needs no CiteCiter migration. Restart the host and refresh its client after local installation.

184 behaviour tests, Host/Client type checks, builds and a real keyless DSH regression passed. See the [validation record](../validation/2026-09-12-acceptance.md) for packaged installation, real Web/Desktop interaction and model results. Native integration supports UTF-8 source text with Session addresses, not built-in renderer selections, PDF text layers, Word or OCR. Actual wheel input, first-turn routing, native fullscreen and floating viewing were checked. Some theme, DPI, mode and custom-setting combinations remain uncovered. The real model completes the workflow but can retain false generalizations and inaccurate source locators after self-checking; workflow success does not establish factual accuracy.
