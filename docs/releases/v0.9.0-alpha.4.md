# CiteCiter 0.9.0-alpha.4 — 候选说明

状态：候选包已构建并安装到本机官方 DSH Desktop，最终候选的重启和功能验收尚未完成；本版本尚未发布到 npm 或 GitHub Release。以下描述区分已实现的变更与已经观察到的运行结果，不代表全部功能通过验收。

## 官方 DSH 与 Git 安装

后续 Desktop 兼容以 DeepSeek 官方桌面版为准。本轮目标为官方 Desktop `0.2.0-rc.2` 和最新 Web SDK `0.2.1-alpha.1`；社区桌面版不再作为支持对象或验收依据，也不保证可用。旧社区版本专属的模块定位、设置、图标、图片预览与布局兼容分支已清理。

仓库根目录增加可供 DSH 识别的插件 bundle 入口，统一根包与插件子包的补丁位置、导出和安装元数据。使用 pnpm `11.7` 对本地真实 Git 快照的安装检查已验证 bundle 解析、四个模块导出和 Typert 描述；官方插件管理器中的 Git 安装仍需完成实测，不能用本地解析结果替代。源码变更提交并推送后，用户才能从远端仓库取得这些变更。

宿主模块解析、设置和 UI 适配跟随官方 SDK，分别检查官方 Desktop RC 与最新 Web alpha。官方 Windows 标题栏和 alpha 底部布局占位纳入适配，实际宽窄窗口、悬浮/停靠和详情优先行为仍在本轮验收范围内。

## 原生问答兼容

适配新版原生问题卡的 `dismiss()`、支持详情文本和已回答内容的只读查看。默认阻塞提问仍由用户回答或取消，不自动改为限时提问。

用户在 DSH 启用 timed 提问后，Citer 使用宿主公开等待接口接收剩余时长。输入区获得焦点时暂停尚未编辑的倒计时，失焦后恢复；首次编辑或选择“等我回答”后保持等待。收起卡片或切换 Topic 不销毁计时器；超时后仍可从原 Topic 补答。命名的工具问题支持显式跳过；跳过、超时和用户授权保持不同含义。

补答通过原生 `userQuestions.answer()` 写入该 Topic 的 Inbox 与日志；不会进入来源主会话。已归档 Topic 收到用户补答后恢复到活动列表。Citer 继续独立维护自己的会话目录，不把 Topic 显示在 DSH 主会话列表中，不改变只读默认权限和手动发送要求。

问答输入草稿在本次 Client 生命周期内保留，支持收起重开和切换 Topic；本轮没有增加独立问答草稿的跨重启持久化格式。普通消息草稿与已记录的宿主问答日志沿用各自已有的恢复机制。

## 验证与发布门槛

主 SDK 与官方 Desktop SDK 的 Host/Client 类型检查通过，候选包构建、打包和安装文件一致性已核验。官方 Desktop 已实际启动并显示 Citer 入口，DSH Codex Connect 已更新为兼容本次 Desktop 的 `0.2.0-alpha.2`；这不代表最终候选已完成真实模型联调。

最终候选重启后仍须完成真实模型、输入法、附件、问答、权限、会话、布局与组合回归。Linux 本轮不验收，也不新增其他平台通过声明。完整状态、包哈希和阻塞记录见 [官方桌面验收记录](../validation/2026-10-07-official-desktop.md)，上游接口变化见 [国庆兼容审计](../compatibility/2026-10-official-desktop-audit.md)。验收缺口补齐前不判定可发布。
