发布草稿，尚未发布。最新验收状态与候选标识见 [10 月 9 日草稿与宿主复查](../validation/2026-10-09-draft-merge.md)，此前子项见 [10 月 8 日发布前复查](../validation/2026-10-08-release-check.md)。npm 上次核验的默认版本为 0.9.0-alpha.3；以下内容介绍候选变更，不代表已完成全部发布门槛。

## 官方 DSH 与 Git 安装

本版本转向 DeepSeek 官方 Desktop，分别适配官方桌面内置 DSH `0.2.0-rc.2` 和主 Web SDK `0.2.1-alpha.1`。社区桌面版不再保证可用，其专属代码、文档和验收材料已从当前仓库清除，不再作为兼容证据；Git 历史保留。

修复从 Git 仓库根安装时无法识别为插件的问题。根入口直接声明 Citer bundle，并指向仓库中已构建的插件文件；不要求用户在安装时构建，也不依赖另一个 npm 版本。根入口与包元数据由构建检查保持一致。官方插件页对公开提交的安装、启用和重启已取得实际证据，最终发布提交仍须核对安装产物。

修复 Windows 官方 Desktop 在部分启动路径下无法恢复 Topic 的问题。Citer 通过宿主的 Profile 依赖解析机制加载共享 SDK，避免绝对文件地址绕过宿主解析后产生重复模块和提示词注册。

## 问题卡与草稿恢复

未提交的问题卡答案现在与普通输入草稿一样，由所属 Topic 独立保存。选项、题页、自填文字、代码缩进与首尾空白可恢复，输入同步回显，后台静默保存。多个窗口的独立修改自动合并，重叠修改以正在操作的窗口为准，不再显示保存进度或版本选择按钮。中文输入法组词期间推迟远端合并，避免打断候选文字。

问题卡在选项和自定义答案之间切换时保留完整的用户选择，不会把两个窗口互斥的答案拼在一起；不同题目的修改仍可合并。合并期间保持正在操作窗口的题页，不打断当前答案的输入。

修复整组答案填写完成后，点击“下一个”可能误提交的问题。翻页与提交使用独立按钮，翻页不会启动模型；只有手动提交整组答案才继续回答。

官方宿主退出使等待中的问题中断后，Citer 依据真实日志恢复可补答问题与草稿。用户手动提交后才继续模型流程；明确取消或主动停止的问题不会重新出现。排队期间保留答案，实际接纳后清空；终态记录拒绝旧修订再次保存。恢复、保存和切换 Topic 均不会自动发送。

永久删除仍限定于 Citer 自有 Topic。独立删除回执仅保留精确身份和清理状态，不含答案、附件或会话正文；客户端据此释放问题卡、会话监听和未完成提交，避免已删除 Topic 被晚到操作重新使用。具体删除与并发边界按验收记录分别标注。

## 工具结果与界面修复

- 普通工具及 PTC 子调用分别显示成功、失败、取消、中断和明确审批拒绝；保留原始参数、结果与日志。
- 补答显示为可阅读的用户消息，工具行标记已补答；无原始子结果时不再把参数 JSON 当作补答摘要。
- 原生图片预览的关闭按钮避开官方 Desktop 标题栏，关闭图片不会误触应用关闭。
- 草稿图片解码失败时显示明确的预览不可用提示，保留原文件和移除入口，避免空缩略图掩盖损坏附件。
- 同一模型失败已在当前历史错误卡呈现时，省略底部完全相同的重复告警；其他操作错误仍显示。
- 关闭面板后从轮盘追加到已有 Topic，会在布局就绪后直接聚焦输入框；保留已有草稿，关闭或切换时取消旧聚焦操作。
- 板书引用保留 SVG/HTML 图示中的实际文字，公式和表格按原格式预览；纯图像引用保留视觉核对提示，不再只附上一个空洞的元素编号。

默认权限保持只读。创建 Topic、选择轮盘动作或点击建议追问只准备草稿；修改文件需遵循 DSH 的明确权限选择或单次审批。学习路线默认关闭。自由提问只追加当前来源下已选中的未归档 Topic，没有可用选中项时新建。

## 验证范围与已知外部限制

主 SDK 与官方 Desktop 的 Host/Client 类型检查、构建、工作区 peer 检查及 `git diff --check` 通过。真实模型验收已覆盖记录中的问答恢复、PTC 中断与补答、排队保稿、取消与停止、来源隔离、只读拒绝和单次允许、混合文件/图片读取、重启草稿和原生下载字节一致。不同候选的证据分别标识，静态通过不替代实际界面与持久化核对。

官方 Desktop Host 重启后，另一个浏览器窗口可能原位重连白屏；禁用 Citer 后仍可复现，刷新可恢复，见 [外部宿主重连记录](../compatibility/official-desktop-reconnect.md)。宿主 PowerShell 退出码异常保留为外部限制。Profile 的 pnpm peer 提示与宿主实际加载结果分别记录，不把提示改写为通过。

本轮未验收 Linux 或 macOS。含附件删除、真实待回执期间删除、原生重启不复活，以及独立 Web 的队列、PTC、长文、教学和图像编辑已补齐对应观察。真实跨窗口文件拖放、尚未复核的错误呈现/缩放组合、最终 Git 安装产物及发布前检查仍按验收记录收尾；全部必测项完成前，不发布本候选。
