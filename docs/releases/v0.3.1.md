# CiteCiter v0.3.1

v0.3.1 completes the learning-companion workflow introduced in v0.3 while keeping CiteCiter inside the native DSH programming interface.

## Highlights

- The read-only `glob` and `grep` tools let a Topic discover project files and search their contents instead of guessing paths.
- Reasoning, prompt injections, tool calls, tool results, and user questions use compact expandable rows consistent with DSH conversations.
- Topics can ask the user a structured question through DSH's standard interaction flow.
- Active and archived Topic lists now switch, archive, restore, and reopen correctly.
- The plugin launcher, learning dock, and settings use a new whale-girl mascot icon aligned with the project artwork.

## Install or upgrade

```sh
dsh plugin --profile web add @kirkchinese/dsh-citeciter@0.3.1
dsh plugin --profile web list --depth 0
```

Restart the corresponding DSH Web process after installation or upgrade. This release targets DSH Web `>=0.1.0-rc.7 <0.1.0-rc.8` and Node.js `^22.19.0 || >=24.0.0`.
