# CiteCiter 0.9.0-alpha.3

修复 0.9.0-alpha.1 / alpha.2 的输入法组合输入回归。发布时默认安装标签为 npm latest / next，GitHub 保留 prerelease。宿主基线为 Web DSH 0.1.7-rc.2。

## 修复

持久草稿重构在每次输入时都等待异步读取，即使草稿已经加载。React 因而先恢复旧输入值，打断浏览器正在进行的输入法组合：拼音 n → ni → 你 实际变成 nni你。旧版同步 React 状态没有这一步等待。现在已加载草稿立即更新界面，后台保存继续异步进行；首次载入仍等待完整草稿和附件恢复。

删除输入框上方反复出现的“保存草稿…”文字。自动保存继续运行，保存失败、附件恢复失败和多窗口冲突仍显示处理提示。不会因隐藏进度文字而丢弃错误。

会话目录、权限、引用授权、发送收据与发送期间新增编辑的保留规则均不改变。不修改 DSH Agent Loop，不迁移或降级日志。

## 升级

Web：

```powershell
dsh plugin --profile web add @kirkchinese/dsh-citeciter@0.9.0-alpha.3
```

安装后重启对应宿主。同一个 DSH home 不同时运行多个写入进程。0.9.0-alpha.1 / alpha.2 用户应升级；0.8.2 仍只适用于旧 DSH 0.1.5 基线。
