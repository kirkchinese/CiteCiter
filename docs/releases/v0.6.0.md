# CiteCiter 0.6.0 — Windows、Web 与 Desktop 适配

版本：0.6.0。日期：2026-09-07。

本版本修复新版 DSH 加载 CiteCiter 时的 `effectiveSandboxMode` ESM 导出错误，并迁移会话、沙箱、交互提问和客户端接口。学习栏继续与主对话并排；最大比例和窄窗口下不再覆盖主内容。

## 用户可见变化

- 主对话、原生详情和学习栏分别分配空间。偏好比例 28%–55% 保留；空间不足时限制实际宽度，主对话至少保留 480 CSS 像素。
- 不能容纳可读双栏时，学习栏移到下方。关闭学习栏会恢复宿主列宽和行高。
- 较窄学习栏改用 Topic 下拉选择，释放正文宽度；新建、归档和切换 Topic 仍可直接访问。
- Desktop 标题栏保留独立空间。未知宿主布局给出兼容提示，避免使用遮挡主内容的完整浮层。
- 修复新版 Host 作用域中的只读策略、Topic 用户提问和客户端设置/会话读取。
- 更新提醒按 Desktop 当前 profile 生成安装命令；Web 默认为 `web`，自定义 Web profile 需自行替换命令中的名称。

## 实现变化

Host 增加私有 Session Projection 和 Sandbox Policy，通过注入后的服务设置只读模式。新版会话创建使用 `isSeeded` 与独立的 `inheritedEventCount`，重开 Topic 时仍能区分来源前缀和已有追问。用户提问在对应 Topic agent 作用域处理，避免注册过时的全局 provider。

Client 使用公开 slot、会话 binding/chat projection 和 SnapshotSelectorHook。React 组件接收快照 hooks 与业务回调，Host/Client 分别编译，避免同名服务声明混用。宿主没有公开 dock 尺寸 API，因此仅空间分配保留独立、可清理的布局适配器；没有修改 DSH 核心或替换 Agent Loop。

Windows watch 直接通过 Node 启动编译器和打包器。新增真实应用快照入口，在临时 profile 中运行无密钥模型；可以验证工作区链接，也可以验证 tarball 安装路径。旧 0.5 手写日志 seeder 不作为本版验收入口。

## 升级与回滚

升级前停止使用待升级的宿主，备份其 profile、settings 和 `citeciter/` 数据。安装固定的 DSH 与 CiteCiter 版本：

```powershell
npm install -g @deepseek-ai/dsh@0.1.2-rc.1
dsh plugin --profile web add @kirkchinese/dsh-citeciter@0.6.0
dsh plugin --profile web list --depth 0
dsh web
```

Desktop 安装需设置与桌面相同的 `DSH_HOME`，并将 `web` 替换成当前桌面 profile（通常为 `desktop`），安装后重启 Desktop。全局 npm 更新不替换桌面内置运行时。Web 与 Desktop 同时使用时分配不同 home。仓库的 `scripts/start-desktop.ps1` 默认使用用户目录下 `.dsh-citeciter-desktop`；先在这个 home 安装 `desktop` profile，再使用脚本启动。安装位置可通过 `-DesktopExe` 参数覆盖。

也可下载本 Release 的 `kirkchinese-dsh-citeciter-0.6.0.tgz` 附件，校对 `SHA256SUMS.txt` 后，把上述安装参数替换为 tarball 的绝对路径。安装完成应列出 CiteCiter 0.6.0。若曾为绕过旧插件加载错误禁用了 CiteCiter，升级后需恢复该插件配置，再重启宿主。

npm 12 如果阻止此 DSH 版本的安装脚本，按其警告一次性允许列出的依赖：

```powershell
npm install -g @deepseek-ai/dsh@0.1.2-rc.1 --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty,@google/genai,protobufjs
```

0.6 不批量改写旧日志。DSH 的物理 JSONL 版本 0 仍使用 `seedLength`，新运行时把它投影为 `isSeeded` 与继承数量。已验证一个真实旧 Observer Topic 副本读取成功；这不等于承诺所有历史事件均兼容。遇到拒绝读取时保留原件，回到与数据匹配的旧宿主诊断。

回滚使用成对的 CiteCiter/DSH 版本和升级前的数据备份；不要仅将插件降级后继续写入已被新版运行时修改的数据。

## English

CiteCiter 0.6.0 targets DSH 0.1.2-rc.1 and DSH Desktop 2.0.5 on Windows. It migrates sandbox/session/question/client APIs, separates Host and Client compilation, and retains a parallel learning workflow. A maintained sizing adapter caps panel width to preserve a readable conversation, uses a bottom row in narrow windows, and restores host layout on close. Narrow panels use a Topic selector.

Install with `dsh plugin --profile web add @kirkchinese/dsh-citeciter@0.6.0`, or use the tarball attached to this release. Desktop installations must use the same DSH home and selected profile as the desktop app; restart the owning host after upgrading. npm updates to the global CLI do not replace Desktop's embedded runtime.

Unit tests, real keyless application snapshots, clean tarball installation and the documented Windows UI checks passed. Linux/macOS UI, alpha releases, real provider behavior and unlisted Desktop combinations remain unverified. Back up the complete DSH home and keep separate homes for concurrently running Web and Desktop instances. The next learning-workspace design is not included in 0.6.0.
