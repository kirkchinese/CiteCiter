# CiteCiter 0.9.0-alpha.2

本版保留预发布版本号，已发布到 npm，`latest` 与 `next` 均指向 0.9.0-alpha.2，让默认安装获得适配 DSH 0.1.7-rc.2 的版本。GitHub 仍标记为 prerelease。原有功能与兼容范围见 [alpha.1](v0.9.0-alpha.1.md)；本次不改变会话、草稿、模型权限或教学流程。

## 修复

旧更新检查假定 latest 永远是正式版本；当标签指向 alpha 时，版本比较返回 registry-version-invalid，RPC 结果校验也拒绝预发布版本号。现在版本校验与比较统一使用独立 package-version 模块和 npm 的 SemVer 实现，支持预发布标识及构建元数据。

同一版本不提示升级；alpha.2 高于 alpha.1，alpha.10 高于 alpha.2，同一主版本的正式版高于所有预发布。构建元数据不影响优先级，较旧 latest 不产生降级提示。版本字段仍拒绝空白、v 前缀、范围、标签、非法数字前导零和命令片段；缓存、取消、字节上限与网络权限不变。

0.8.2 与 alpha.1 的已发布代码无法原地修复，旧内置更新检查可能无法发现此次预发布。请使用安装命令升级，不依赖旧版更新提示。

## 安装

Web DSH 0.1.7-rc.2：

```powershell
dsh plugin --profile web add @kirkchinese/dsh-citeciter@0.9.0-alpha.2
```

安装后重启对应宿主，同一主目录不同时运行两个宿主。旧 DSH 0.1.5-rc.1 继续显式使用 0.8.2。
