# CiteCiter 0.7.0-beta.1 · 学习工作台开发预览

本版本在 0.6.0 正式发布后开发，尚未发布到 npm，也不替换稳定 `latest`。DSH 基线仍为 `0.1.2-rc.1`，Desktop 目标仍为 `2.0.5`；alpha 是独立迁移目标。

## 学习流程

路线调整为 **底层逻辑 → 定性分析 → 定量分析（板书）→ 概念关联 → 总结学习卡片**。用户可以跳过、回到任一阶段或自由追问；选择阶段不会自动调用模型，发送后只请求当前阶段。完整阶段指令和补充问题作为普通用户消息写入 Topic，重开后可恢复最近请求的阶段。阶段选中状态不代表已掌握。

主动回忆是可选设置，默认关闭。卡片默认直接显示结论与例子；开启后先看问题，再展开结论与参考答案。不提供间隔复习、到期提醒、打卡或掌握分数。

## 界面与实现

- 讲解、板书、学习卡统一放在学习栏。顶部选择 Topic，标题、模型、思考强度与管理动作按需展开；保留宿主主对话、原生详情与 Desktop 标题栏的独立空间。
- 窄窗口默认收起阶段导航；查看板书或卡片时将输入框折叠为操作栏，可随时展开补充问题。正文自动跟随最新回复；向上阅读时不会被强行拉回。
- 所有 Topic 场景均可使用私有 `blackboard_apply` 和 `learning_cards`。文件写入、命令执行等工具仍不可用。板书侧栏支持条目阅读和原始画布两种方式，继续复用安全渲染器。
- `learning_cards` 一次提交完整卡片组，包含标题、结论、例子、自测问题和参考答案。Host 严格校验 1–8 张与字段长度。只投影成功、完整的工具记录；无效或未完成记录不能覆盖上一组。卡片随 Topic 日志保存，重启可恢复，无新存储格式迁移。
- 支持带 Topic 与引用信息的 Markdown 导出。修订通过追问生成新组，旧组仍留在 Topic 记录。当前没有独立的手工卡片编辑器。
- 追问建议与板书引用追加到草稿后再发送。草稿按 Topic 在本页保留，刷新或重启不恢复未发送内容；`Ctrl/⌘ + Enter` 发送，Enter 换行。
- 更新检查接受本地 prerelease 版本；稳定 0.6.0 不会被误报为 0.7 beta 的升级，未来稳定 0.7.0 可以提示升级。

## English

This development preview follows the stable 0.6.0 release and is not published to npm. It retains DSH 0.1.2-rc.1 and Desktop 2.0.5 as targets.

The learning route is underlying logic, qualitative analysis, quantitative analysis with a board, concept connections, and summary learning cards. Stages are optional entry points: selecting one does not call the model, sending requests only that stage, and selection never implies mastery. Instructions and user input remain visible in the Topic log.

Explain, Board and Learning Cards share one panel. Secondary controls expand on demand, narrow windows fold navigation and the reading-mode composer, and suggestions append to Topic-specific page-local drafts. Panel boards support readable entries and a spatial canvas. All scenarios can use private board and card tools while source access remains read-only.

Card sets persist through successful tool records, restore after restart, and export as Markdown with Topic provenance. Revision is a follow-up request; the latest complete set replaces the display while older sets remain in the log. Active recall is optional and disabled by default. There is no spaced repetition, reminder queue or mastery score. Manual card editing, cross-Topic search, a knowledge-graph database and cross-device sync are not included.

Local validation includes separate Host/Client typechecks, 148 behavior tests, build, a real keyless Observer/Exact Fork snapshot and a second host boot to check restoration. See the Agent Note for UI and tarball evidence and platform limits. Deterministic fixtures do not establish real-model teaching quality.
