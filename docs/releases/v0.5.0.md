# CiteCiter v0.5.0

这个版本把 CiteCiter 从选区问答扩展为完整的只读学习工作区，并加入 Presenter 小黑板与 Web 更新提醒。

## 新功能

- 可以直接新建无引用的自由 Topic，并在“问答”和“讲解”形态之间选择。
- Presenter 会通过协议 v4 原子更新小黑板；支持文本、Markdown、表格、数学公式、安全 SVG/HTML 预览、聚焦和动画。黑板元素可以引用到追问输入框。
- 新增独立 Reader、工具结果入口、快捷键、Topic 模型与思考强度设置。
- Topic 支持归档、恢复和需要 Session ID 确认的永久删除；删除不会改写来源 Session。
- EvidenceRef v4 统一保存主回答、思考、工具结果和文档范围来源。
- Web 检测到 npm 稳定新版时，在右上角显示“更新”“下次一定”“不再提示”。更新操作只复制命令，不会静默安装或重启 DSH。

## 体验与安全修复

- 宽屏时主工作区小黑板、右侧学习对话和 Topic 列表并排显示；窄屏自动收起 Topic 列并保留紧凑选择器。
- 新建与删除弹窗适配窄栏，具备焦点陷阱、背景 inert 和焦点返回；编辑框获得清晰键盘焦点样式。
- KaTeX 样式和 woff2 字体内联到 Client bundle，不依赖外部字体请求。
- Markdown 黑板不加载远程图片；SVG/HTML 预览经过白名单和无网络 CSP 约束。
- 空白主会话会给出可执行的中文模型路由提示；关闭失败弹窗后不会保留过期告警。

## 安装或升级

```sh

dsh plugin --profile web list --depth 0
```

确认列表显示 `@kirkchinese/dsh-citeciter@0.5.0` 后，重启 DSH Web 并刷新页面。旧 Topic、设置和来源 Session 不需要迁移或重写。
