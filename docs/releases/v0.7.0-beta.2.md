# CiteCiter 0.7.0-beta.2

开发候选，未发布 npm，不修改稳定 latest。目标为 DSH `0.1.5-rc.1` 和社区 DSH Desktop `2.0.9`。稳定 0.6.0 继续对应 DSH 0.1.2-rc.1 / Desktop 2.0.5。

## 宿主适配

- Agent setup 使用显式 Agent 参数，注册和清理仍归属 Agent scope。
- 实时讲解订阅 `agent/assistant-stream`，完成后使用持久记录；失败或停止保留已生成的文字。失败尝试从 `assistant/attempt` 的压缩流恢复，不伪造模型可见消息。
- 持久读取改用 `sessionPersistence.open(id, 'read')`，始终关闭 handle。DSH 负责旧日志迁移和当前格式文件的写入。
- Exact Fork 读取恢复后的继承前缀。标题投影使用 `inheritedEventCount`，避免宿主迁移改变序号后读取越界或漏掉 Topic 标题。历史引用保留原文；旧序号可能不再对应迁移后的来源事件，模型需核对工具返回的引文。
- 永久删除清理私有 Topic 的所有标准 JSONL 版本文件。删除只在 Agent 退出后执行，校验固定私有目录及 Topic 标识；不跟随目录链接。
- 适配原生右侧栏的尺寸柄与全屏状态。原生全屏时撤销学习栏占位，退出后恢复；最大比例继续保留主对话空间。

## 学习与阅读

五阶段为底层逻辑、定性分析、定量分析（板书）、概念关联、总结学习卡片。阶段可跳过、重复或切回自由追问；选择阶段不调用模型，发送后才请求该阶段。主动回忆可选且默认关闭，不提供间隔复习、提醒或掌握分数。

学习栏包含讲解、板书和学习卡。模型通过 `learning_cards` 提交完整卡片组，界面读取最新成功记录，并支持 Markdown 导出。旧组保留在 Topic 日志中；无效或未完成记录不覆盖上一组。板书提供条目阅读和空间画布。修订通过追问生成新组，未发送草稿仅在当前页面内保留。

阅读器保存完整文本，按每页最多 500 KiB UTF-8 分页，导入上限为 2,000,000 个字符。翻页保留问题、清除旧选区；创建 Topic 成功后收起阅读器并显示学习栏，失败保留问题和选区。文档 Topic 在用户开启来源文件访问时可使用只读项目工具辅助解释。

修复长 Markdown 引用的调用栈溢出、切换文档时的过期响应覆盖、未处理的 Promise 拒绝、本地文件读取失败和损坏元数据读取。宿主模态窗口暂时隐藏插件浮层。原生板书引用打开讲解输入视图，使新草稿可见；引用保留当前阶段，发送时按该阶段处理。

## 安装和验证

从开发分支构建 tarball，在 Web 或 Desktop 各自的 CLI 中安装，步骤见 [README](../../README.md) 与 [贡献指南](../../CONTRIBUTING.zh.md)。Desktop 内置 CLI 自动选择当前 profile；全局 CLI 不管理保留的 desktop profile。安装后重启宿主。升级前备份数据，测试使用独立 home。

本地通过 Host/Client 类型检查、165 项行为测试、构建和无密钥真实宿主测试。实际 tarball 验收覆盖 Observer、Exact Fork、五阶段、板书、学习卡、长文档末页引用、模型配置、管理操作、流式停止、部分输出后失败和重启追问。详细的旧数据迁移和界面覆盖见 [验收记录](../validation/2026-09-11-latest.md)。

## English

This unpublished candidate targets DSH 0.1.5-rc.1 and community Desktop 2.0.9. Stable 0.6.0 remains on DSH 0.1.2-rc.1 / Desktop 2.0.5.

Agent setup uses the explicit Agent argument. Live output follows the scoped assistant-stream event and settles into durable messages or attempts. Read handles always close. DSH owns Session format migration; Exact Fork and title projection use the restored inherited prefix, and permanent deletion removes all canonical generations within the private Topic directory. Historical quotes retain their text, while captured sequence numbers can change after host migration. Native right-sidebar fullscreen temporarily releases the learning panel reservation.

The learning route is underlying logic, qualitative analysis, quantitative analysis with a board, concept connections, and summary cards. Selecting a stage does not call the model. Active recall is optional and off by default; there is no spaced repetition. Complete card sets persist through successful tool records and export to Markdown. The reader retains full imports, pages within a 500 KiB UTF-8 budget, preserves questions across pages, and closes only after Topic creation succeeds. Reading Topics may use enabled read-only project tools.

Fixes cover large Markdown stack overflow, stale document responses, rejected promises, local file failures, persisted metadata validation, modal overlay visibility and hidden board-citation drafts. Board citations retain the selected stage when sent. Local checks include separate Host/Client typechecks, 165 behavior tests, build and real keyless packed-host acceptance. See the acceptance record for migration, restart and native UI evidence and remaining gaps. The candidate is pushed for review without npm publication.
