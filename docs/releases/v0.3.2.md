# CiteCiter v0.3.2

v0.3.2 is a reliability release for model-call citations, private Topic state, and the learning dock. It targets DSH Web `>=0.1.0-rc.7 <0.1.0-rc.8` and does not change the existing Topic metadata or Session log formats.

## Reliability fixes

- The Host resolves browser selection claims against the committed `assistant/message` Markdown, so inherited branch content, GFM, inline code, repeated text, translated paragraphs, and UTF-16 ranges do not depend on the browser's projected copy.
- Topic metadata is atomically committed before the first private Agent request can use source tools; failed creation is rolled back and request ids remain idempotent.
- Exact Fork uses the completed source turn boundary, reports Observer fallback for an open turn, ignores inherited source titles, and generates one title from the first post-seed CiteCiter question.
- Model route and reasoning effort writes are serialized per Topic and use independent Client response ordering, preventing late responses from reverting newer choices.
- Topic lists use navigation metadata and hydrate a missing cached title once instead of replaying every Topic and reading every source Session on each poll.
- Archiving, restoring, last-Topic reopening, source availability, and dock-width persistence keep their current source and request state during overlapping refreshes.
- Disabling source workspace investigation removes `read`, `glob`, and `grep` from the next model request while `read_source_session` and `ask_user_question` remain available; write and command tools remain absent.
- Malformed follow-up control blocks never leak into the visible answer. Only one valid terminal block containing exactly three unique questions creates shortcuts.

## Compatibility

The Host accepts both the v0.3.1 `{ citation }` create request and the v0.3.2 `{ selectionClaim }` request during a hot upgrade. It also accepts the v0.3.1 `select-model` command beside the split `set-model-route` and `set-reasoning-effort` commands. Existing `topic.json` files and private DSH Session logs are read without migration or rewrite.

## Install or upgrade

```sh
dsh plugin --profile web add @kirkchinese/dsh-citeciter@0.3.2
dsh plugin --profile web list --depth 0
```

Restart the corresponding DSH Web process after installation or upgrade.
