## 安装包与交付

最终 tarball 经内容摘要命名后，在另一个全新 profile 中安装；真实无密钥 Host 的完整快照与第二次启动恢复通过。随后使用 Web 官方 CLI 和 Desktop 内置 CLI 安装到本机各自的插件 profile，两个命令均以 0 退出。实际安装版本均为 0.7.0-beta.3；index、client 和两个 Typert 运行 bundle 的 SHA-256 均与构建输出一致。

安装前备份 profile 的清单与锁文件。没有停止用户日常宿主；运行中的窗口需要重启并刷新客户端后加载新代码。仅停止本轮拥有的临时 Web 进程。最终提交的远端 CI 结果单独报告，不把 beta.2 或先前提交的绿色状态算作本提交的结果。
