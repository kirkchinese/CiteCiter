# 2026-09-12–14 Web 真实模型验收

历史范围：Web DSH 0.1.5-rc.1、Codex Connect 4.34，使用真实来源分支与 DeepSeek V4 Flash Vision Exp Max。本文仅保留可归属于 Web 的验收与通用修复，不构成当前版本兼容结论。

## 通用修复

来源读取使用公开 sessionQuery.observeSession 并释放观察器，避免把 seeded 分支当作普通 readSession 打开。Agent 依赖显式声明，作用域注册使用 agent.ctx.plugin；不修改宿主 Agent Loop。

Citer 会话、归档、草稿和删除由来源实体目录下的 citeciter/ 独立管理；已迁移的旧副本保留备份。主列表混入已加载 Topic 的原因是会话服务成员关系，不能归因为递归扫描目录。发送通过 requestId 与接收收据区分未接收失败和已接收请求；热卸载停止接收、取消工作并等待释放。

模型长名布局允许缩小；公式字号继承板书设置；后台截图按确切 Topic 和 revision 渲染。可选文档预览识别 mjs、cjs、mts、cts。混合剪贴板输入保留文字与图片，损坏图片报告 INVALID_IMAGE 并保留草稿。

| --- | --- |

| 重启 | 主 Web 重启后原对话、板书及工作区状态恢复，没有自动开始模型请求 |

模型曾错误概括 Promise.all 的拒绝处理；通过真实 JavaScript 实验及 [ECMAScript PerformPromiseAll](https://tc39.es/ecma262/multipage/control-abstraction-objects.html#sec-performpromiseall) 对照纠正。流畅解释与成功工具调用不构成答案正确的保证，学习卡应核对结论并标明未核实内容。

文件拖放归属在独立面板控制器中处理，并阻断事件继续传播到来源输入区；该实现记录本身不补充新的拖放实机通过声明。原生工具和宿主错误保留参数与结果，不以隐藏输出代替修复。
