# 0.7 beta.3 Windows Web 功能验收

日期：2026-09-12。Web 基线为 DSH `0.1.5-rc.1`、Node `24.19.0`、pnpm `11.21.0`。仅保留明确的 Web 检查与通用工程结论；此前记录见 [轮盘验收](2026-09-11-wheel.md)。

## 修复

客户端公开 façade 改为完整转发首轮模型与捕获来源参数。轮盘取消与问题草稿关闭分离，避免失焦或窗口变化清空文字和模型。插件浮层使用公开 slot 管理的 React portal，解决全屏原生预览的父级层叠遮挡；侧边布局仍由独立适配器管理。

文档阅读使用原文字面定位与原始上下文消歧；对话选文继续使用渲染后 Markdown 匹配。用户确认总结卡片前应在同一请求中核对、纠错并标明无法核实的内容；工具只检查结构，不保证事实正确。

184 项行为测试、Host/Client 类型检查、构建与最终 tarball 的干净 profile 回归通过。真实 DSH 确定性流程覆盖来源、Topic、板书、卡片与重启恢复；总结指令变更只更新两条用户消息，其余输出快照未重录。此证据不证明真实模型准确率。

## 单一小黑板与输入区

移除学习侧栏内重复板书，统一使用主区“小黑板”。TopicComposer、TopicModelControls 和 TopicSettingsDialog 分别拥有视图与样式，只通过数据和回调组合。

最终包摘要前缀 `f3d5014de097`。Web 实际操作验证模型/思考强度、定量生成、唯一板书、引用保留阶段、重命名、归档恢复、删除需完整 ID、关闭后引用重开。900×700 侧边和 650×700 窄布局中输入控件位于面板内。Web 安装文件与构建一致。

## 内容质量边界

当时真实模型自查曾继续沿用错误数学推广和不准确的来源定位，因此保留“自查不能替代独立证据”的产品教训，不把保存卡片成功称为结论正确。数学核对参考：[Dubrovin 几何讲义](https://people.sissa.it/~dubrovin/dg.pdf)、[UCSD 离散微分几何讲义](https://cseweb.ucsd.edu/~alchern/teaching/DDG.pdf)和 [Oregon State 平坦环面说明](https://sites.science.oregonstate.edu/physics/coursewikis/GDF/book/gdf/torus.html)。平坦环面指平面按平移粘合的度量及 Levi-Civita 联络，不推广至任意平坦丛。

系统 DPI、全部触发键、主题和自定义设置组合未完全覆盖。构建和推送没有执行 npm 或 GitHub 发布；临时凭据、会话、截图和安装包未入库。
