# CiteCiter DSH Web 0.1.5 历史验收

候选版本 `0.7.0-beta.2`，当时未发布 npm。目标为 DSH Web `0.1.5-rc.1`，环境为 Windows、Node `24.19.0`、pnpm `11.21.0`。旧阶段结果见 [9 月 10 日记录](2026-09-10.md)。

## 安装与工程检查

最终 tarball 在干净 Web profile 安装，之后安装到本机默认 home 的 Web profile。安装退出码为 0，Client bundle 摘要与构建一致；升级前保留 profile 清单和锁文件。测试进程使用独立 home，未停止日常 Web 进程。

Host/Client 类型检查、165 项行为测试、构建与真实 DSH 确定性模型检查通过。覆盖 Observer / Exact Fork、五阶段、板书、完整卡片更新、模型提问与取消、模型配置与无效路由回滚、归档删除边界、流式停止、部分输出后失败及恢复、长文 Unicode 分页和末页引用、重启后来源读取与来源事件不变性。确定性输出未为迁移重录，不能证明真实模型教学质量。

## 数据与接口

DSH 负责 Session v0 到 v3 的迁移。Citer 不改写旧 `seedLength` 或事件记录；Exact Fork 与标题投影使用恢复后的 `inheritedEventCount`。历史引文保留文本，原序号不能保证仍对应迁移后的事件。私有 Topic 删除校验目录归属，清理所有标准日志版本，不跟随目录链接。

## Web UI 边界

独立 Web 服务与真实 Host 检查通过。浏览器工具最初无法读取 request-header policy；恢复到可枚举浏览器后，本地地址仍返回 `ERR_BLOCKED_BY_CLIENT`，新的 Web 交互验收未完成，未绕过限制。Linux/macOS 界面与真实模型质量不属于通过项。

当时用户确认板书引用保留所选学习阶段；这是历史产品决定，当前流程以现行产品规则为准。中英 README、功能示意 SVG 和 [beta.2 说明](../releases/v0.7.0-beta.2.md) 同步更新。原始日志、截图、临时 home、凭据和 tarball 不入库。
