# CiteCiter 旧 Web 基线阶段验收记录

本记录仅保留 DSH Web `0.1.2-rc.1`、CiteCiter `0.7.0-beta.1` 的历史工程检查，最终迁移阶段见 [9 月 11 日记录](2026-09-11-latest.md)。环境为 Windows、Node `24.19.0`、pnpm `11.21.0`；起点为 `470cb74f4e002f33c634b080bb1ebdd0127d107c`，当时未发布 npm。

## 当时确认的行为与修复

长文档保存全文，按每页最多 500 KiB UTF-8 分页；从文档创建 Topic 成功后才收起阅读器，失败保留选区和问题。文档 Topic 的来源项目文件访问由只读开关控制。以下为该版本的历史行为，不覆盖后续产品决定。

修复大段 Markdown 引用的参数展开导致的调用栈溢出、快速切换文档后的过期响应覆盖、未处理 Promise 拒绝、本地读取失败、创建失败误清空问题、板书引用后草稿不可见和损坏元数据直接使用。文档元数据读取校验版本、格式、标识与字节数。

## 工程证据

Host/Client 类型检查、160 项行为测试、构建、真实 DSH 的确定性模型快照和最终打包安装检查通过。覆盖 Observer / Exact Fork、五阶段、板书、卡片、停止与失败恢复、管理、长文末页引用、来源事件序列保持不变及第二次启动恢复。模型由当时的确定性夹具提供，不能据此评价真实模型的教学质量；这些旧测试入口不代表当前保留的工程工具。

本轮浏览器连接反复返回 `Unable to load browser request-header policy`，新的 Web 交互验收未完成。此前 [9 月 7 日 Web 记录](../../.agents/notes/2026-09-07-learning-workspace.md) 不替代本轮修改后的 UI 回归；Linux/macOS 界面未验证。
