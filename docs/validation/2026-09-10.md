# CiteCiter 旧基线阶段验收记录

本记录仅描述切换到最新版之前的阶段；最终基线与结果见 [9 月 11 日记录](2026-09-11-latest.md)。

状态：候选构建验收，尚未发布 npm。本轮从远端 `codex/learning-workspace-0.7` 的 `470cb74f4e002f33c634b080bb1ebdd0127d107c` 开始，版本保持 `0.7.0-beta.1`。用户选择的宿主基线为 DSH `0.1.2-rc.1`、DSH Desktop `2.0.5`；Windows 使用 Node `24.19.0`、pnpm `11.21.0`。

## 用户确认的行为

| 场景 | 预期 |
| --- | --- |
| 长文档 | 保存全文，分页阅读，每页最多 500 KiB UTF-8 文本 |
| 从文档创建 Topic | 成功后收起阅读器并显示学习栏；失败保留选区和问题 |
| 文档 Topic 的项目文件访问 | 启用“允许读取来源项目文件”时，允许只读搜索和读取辅助解释 |

五阶段路线为底层逻辑、定性分析、定量分析（板书）、概念关联、总结学习卡片。主动回忆可选且默认关闭，不实现间隔复习。

## 修复与回归

| 问题 | 修复 | 证据 |
| --- | --- | --- |
| 导入超过 500 KiB 后无法阅读后半部分 | `document-get` 增加零起始页码和总页数，按 Unicode 码点分段 | 多页重组与重启读取测试；真实 Host 末页引用 |
| 大段 Markdown 引用导致调用栈溢出 | 消除映射数组追加时的大量函数参数展开 | 18 万字符普通段落、实体强调、缩进代码三个回归用例；修复前失败，修复后通过 |
| 快速切换文档后旧响应覆盖当前文档 | 用请求代次忽略过期响应和错误 | 延迟响应顺序反转测试 |
| 读取失败产生未处理 Promise 拒绝 | 跟踪 `finally` 返回的 Promise；捕获本地文件读取失败 | 拒绝请求与文件读取失败测试 |
| 创建失败被误当作成功，丢失问题 | Companion 向 Reader 传播错误，成功后才关闭 | Reader 与 Companion 联合失败、重试测试 |
| 创建成功后阅读器挡住学习栏 | 成功时自动收起并打开学习栏 | 控制器测试；独立 Desktop 创建点击未完成 |
| Desktop 设置窗口被学习栏遮挡 | 宿主模态窗口打开期间隐藏插件浮层，保留布局和 Topic 状态 | 原生窗口修复前后对照，关闭设置后恢复 |
| 原生板书引用追加后草稿不可见 | 切换到讲解视图并聚焦输入框 | 代码检查；本轮未完成独立点击回归 |
| 损坏文档元数据被直接使用 | 读取时校验版本、格式、文档标识和内容字节数 | 无覆盖写入的损坏数据测试 |
| 测试误用其他版本的全局 DSH | 创建 profile 前核对包版本，支持 `CITECITER_DSH_BIN` | 0.1.5-rc.1 被明确拒绝；固定基线重新验收 |

## 运行时隔离

本轮发现全局 DSH 已为 `0.1.5-rc.1`。同一个插件 Host bundle 在该版本创建 Topic 时报告缺少 `agent` 注入；前后 bundle SHA-256 相同，因此不是重新构建产生的代码差异。0.1.5 不属于本轮适配目标。Web 候选使用独立安装的 0.1.2-rc.1，Desktop 使用其内置 0.1.2-rc.1；两个进程使用不同 home。

Desktop 插件通过内置 CLI 安装。自带终端会选择当前 profile；新版全局 CLI 拒绝保留的 `desktop` profile。安装文档已区分这两条路径。测试候选保持在开发分支，构建、打包和推送不执行发布。

本记录不承诺“无 bug”。已复现问题有对应修复和证据；未完成的界面项目保留为后续验收清单。
