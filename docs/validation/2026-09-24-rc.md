## 已知问题与外部限制

- 只读 PowerShell：DSH pwsh-local 前置的 UTF8Encoding 构造在 ConstrainedLanguage 下失败；Desktop 使用 Windows PowerShell 5.1 时 stderr 还出现乱码。结果中 stdout=391 并不代表整个工具无错误。未隐藏错误、绕开沙箱或修改宿主 Agent Loop。
- 原生控制：重新选择 DSH Desktop 窗口后，截图与普通操作已恢复。Edge URL 识别失败不等于 Desktop 控制失败，也未被声明修复。边缘拖动和窗口尺寸菜单未实际缩窄，故由用户缩窄再原生截图验收。
- 浏览器拦截了一次 blob 图片导航；保留拦截，未用另一浏览器、原始调试协议或文件读取绕过。工具内图片仍能正常显示。
- 清理：6 个临时文件及本轮损坏图片、下载副本删除成功。9 个逐项核对的旧开发目录和 3 个编译诊断目录删除被自动审批拒绝，仅返回 blocked by policy；目录仍保留，未换工具绕过。主目录、用户会话、迁移备份、视频素材与回滚包保留。
- 构建稳定性：TS5033 UNKNOWN 在不同 lib/types 文件再次出现。分离目录、复用目录、清理类型目录后直接编译以及 npm run build:lib 均成功，最终完整 prepack 成功；尚未确定占用者，不能声称已永久修复。
