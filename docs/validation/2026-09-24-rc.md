# 2026-09-24 DSH RC1 Web 验收

历史基线：Web DSH 0.1.7-rc.1、CiteCiter 0.9.0-alpha.1、未修改的 Codex Connect 4.46。下列结果仅属于当时安装的 Web 候选包，不能沿用为当前版本通过。

## 修复与观察

| 范围 | Web 操作与结果 |
| --- | --- |
| 启动 | 重启恢复历史；新 Topic 默认只读、学习路线关闭，创建不自动请求 |
| 草稿 | README（16481 字节）及封面（2015580 字节）与文字在刷新、重启后恢复；手动提交后真实模型读到附件，接收后草稿清空 |
| 发送后滚动 | 修复发送仍停在旧消息的位置；用户发送后到最新，单独模型输出仍尊重旧阅读位置 |
| 异步编辑 | 修复发送快照的捕获时机；事件 3441 的最终候选只提交点击时的文字和两份附件，发送期间新增文字留在 revision 17 草稿 |
| 错误恢复 | 23 字节损坏 PNG 返回明确错误并保留草稿；替换为真实 README 和图片后成功 |

| 归档恢复 | 归档 Topic 4 手动发送后恢复活动列表 |
| PTC | run_code 并行读取两个 package.json，父子调用可见；失败读取和后续回答 42 均可见 |
| 创建耗时 | 两次观测为 617 和 638 ms，含浏览器控制开销，不代表统计分位数 |

Host/Client 类型检查、完整 prepack/build 与 git diff --check 通过。最终 Web 候选的摘要前缀为 3441c3ba77a3；前序包结果不自动移交给变化后的功能。

Windows 构建曾返回 TS5033 / UNKNOWN，独立步骤及后续完整构建通过，但根因未确定。只读 PowerShell 的 UTF8Encoding 初始化与受限语言冲突属于宿主问题，错误输出没有被隐藏，权限未放宽。详见 [复现记录](../compatibility/pwsh-readonly-encoding.md)。
